# DevOps Live Assessment

This repository contains the starter files for a practical DevOps assessment.

## Repository structure

- `app/`: Pre-written HTTP application.
- `config/`: Example application configuration.
- `docker/`: Dockerfile to complete during the assessment.
- `broken-lab/`: Intentionally misconfigured Docker example.

## Instructions

- Follow the tasks provided in the assessment brief.
- Do not modify the application code.
- Explain your reasoning while working.
- Do not commit credentials, secrets, or personal information.
